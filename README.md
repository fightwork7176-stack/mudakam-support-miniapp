# Круг опоры — Telegram Mini App

Оригинальная статическая игра-размышление для Telegram Mini App:
<https://fightwork7176-stack.github.io/mudakam-support-miniapp/>.

Выбери одну тему, пройди три случайных броска и на каждом выбери один из
фиксированных ответов. Игра не диагностирует, не предсказывает и не заменяет
профессиональную помощь.

Веб-страница не подключает аналитику или серверное хранилище. Ответы остаются
в текущем окне игры, пока пользовательница отдельно не согласится передать их
боту. При согласии Telegram Web App отправляет только тему и три пары
«номер клетки + ответ-кнопка» и выбранный следующий шаг. Имена, свободный текст,
контакты и сведения о детях не собираются. Без согласия можно завершить игру
без отправки.

Исходник публикуется через GitHub Pages. Не вводите в игру сведения, по
которым можно идентифицировать вас или других людей.
