# Дорога домой — Telegram Mini App

Публичная статическая версия мини-игры для Telegram: <https://fightwork7176-stack.github.io/mudakam-support-miniapp/>.

Страница не подключает аналитики или сервер хранения. До отдельной отметки согласия кнопка передачи недоступна; завершение без передачи закрывает игру, не отправляя ответы. При согласии Telegram Web App передаёт в чат с ботом только выбранную тему и пять заданных вариантов ответа. Имена, свободный текст, контакты и данные детей в игре не запрашиваются.

Исходник опубликован для размещения через GitHub Pages. Не вводите в игру сведения, по которым можно идентифицировать вас или других людей.
